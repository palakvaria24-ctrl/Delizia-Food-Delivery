# Delizia – Food Delivery Website

## About the Project

Delizia is a frontend food delivery website designed to provide users with a simple and convenient way to explore vegetarian food options from different restaurants.

The website allows users to browse restaurants, view their menus, add food items to a shopping cart, remove items, and view the total amount before placing a demo order.

It is developed using HTML, CSS, and JavaScript.

## Features

- **Home Page:** A welcoming homepage with a food-themed banner.
- **Restaurant Listings:** Displays three popular restaurants.
- **Restaurant Menus:** View food items and prices by selecting a restaurant.
- **Add to Cart:** Add selected food items to the shopping cart.
- **Remove from Cart:** Remove unwanted items from the cart.
- **Cart Total:** Automatically calculates the total price of selected items.
- **Place Order:** Displays an order confirmation message for the demo.
- **Contact Form:** Allows users to enter their name, email, and message.
- **Responsive Design:** CSS styling adjusts the layout for different screen sizes.

## Technologies Used

- **HTML5:** Structure of the website.
- **CSS3:** Styling, layout, animations, and responsive design.
- **JavaScript:** Restaurant menus, cart functionality, total calculation, and form validation.

## How to Run the Project

No additional software or packages are required.

**Step 1:** Download or clone this repository.

**Step 2:** Open the `Delizia` project folder.

**Step 3:** Locate the `index.html` file.

**Step 4:** Double-click `index.html` to open the website in your browser.

Alternatively, open the folder in Visual Studio Code and open `index.html` in your browser.

## How to Use

1. Open the Delizia website.
2. Browse the available restaurants.
3. Select a restaurant to view its food menu.
4. Click **Add to Cart** to select food items.
5. Visit the Cart section to view selected items and the total amount.
6. Remove items if required.
7. Click **Place Order** to see the demo confirmation message.
8. Visit the Contact section to fill out the contact form.

## Project Limitations

This is a frontend demonstration project.

- Orders are not sent to restaurants.
- No online payment system is integrated.
- Cart information is not permanently stored.
- Contact form messages are not sent to a server.

## Purpose of the Project

The purpose of Delizia is to demonstrate the use of HTML, CSS, and JavaScript to create an interactive and responsive food delivery website with restaurant listings, menu browsing, shopping cart functionality, and a contact form.
